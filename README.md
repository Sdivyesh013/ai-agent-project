# Company FAQ Agent

A text/voice chatbot that answers company FAQ and training questions, using:
- Retrieval-Augmented Generation (RAG) over a company knowledge base
- Groq (free, open-source LLM + speech-to-text + text-to-speech)
- FastAPI as the backend
- ChromaDB as a local vector database

Built as a hands-on learning project, starting with dummy/sample content.
